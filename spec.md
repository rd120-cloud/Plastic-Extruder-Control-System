# Design Specifications for RASTIC Plastic Recycler v1.0
This system is an open source elaboration on the ArtMe 3D Mk3S+ plastic extruder. The primary changes made with this system include a more streamlined, boutique operating system; improved filament tolerance monitoring and related control feedback systems; a more responsive and multifunction interface; WiFi functionality to record output statistics; and integrated system controls and open source designs for plastic preprocessing for quality enhancement, including a novel preheating system to dehydrate input stock.

## General System Operation
This system operates with a continuous processing sequence. Each of these stages were experimentally calibrated to produce the most consistent and reliable printer filament.
1) Presort plastic by polymer type (e.g. PLA)
2) Shred plastic
3) Sift plastic (reshred too large parts)
4) [***Optional***] Wash plastic for contaminants
5) Preheat plastic to dry
6) Extrude plastic
7) Check tolerance (feedback to extruder to control spooling and droop)
8) Spool plastic

## Control System Features
**This section is for development specs**

This system runs on a BigTreeTech SKR2 board with standard motor drivers and a CYD with an ESP32. All extruder systems will be managed through the standard BigTreeTech pin-outs, indicated below in the feature I/O descriptions (e.g. Feature (desc.) - Pins). The listed priority of each feature is the RTOS priority, which is based on the safety requirements of the system such that high priority features will supercede others for safety checks in the RTOS scheduler. The CYD ESP32 will be used to manage control features (e.g. encoders), and the display and WiFi features will be used for live logging of extrusion. All external systems (e.g. shredder, sifter) will be relay controlled through the CYD ESP32, as these features are optional and can be managed through their own external control systems.

Specifications for this board can be found at: https://github.com/bigtreetech/SKR-2
Pins will be referenced using board pin names. Pin assignment is being accomplished through a custom STM32CubeMX build project. All subsequent operation code will be included through the prefered "user code" structure generated by STM32CubeMX autogenerated scripts.

Main features of control system:
- Motor control 
  - Extruder (High priority) - Motor E0
  - Puller (Medium priority) - Motor X
  - Spooler (Medium priority) - Motor Y
- Preheater control (Highest priority!!!)
  - Preheater 
  - Temperature sensor - TH0
- Heater control (Highest priority!!!)
  - Heater
  - Temperature sensor - TH1
- Fans (Medium Priority)
  - Extruder fan - Fan1
  - Puller fan - Fan2
  - Preheater fan - Fan0
- Tolerance feedback mechanisms (Medium priority)
  - Plastic droop mechanism (aka. arm sensor)
  - Plastic diameter magnetic sensor (aka. magnetic sensor)
- SKR2 Buttons
  - Emergency stop (kill all systems during extrusion. If in preheat phase, stops preheat) (Highest priority!!!) - X-Stop
  - Pause (keep heat on, stop extrusion and pulling. When not extruding, also starts preheat phase) (High priority) - Y-Stop
  - Begin extrusion (Medium priority) - Z-Stop
- I/O (ESP32)
  - CYD (Low priority) 
  - Encoders (Medium priority)
    - Extruder speed
    - Puller speed
    - Heater temp.
    - Preheat temp.
    - General encoder (settings) (Low priority)
  - Buttons
    - General encoder button (settings) (Low priority)
  - Default operation & presets
  - **Optional**: Shredder and sifter command interface (Low priority)
